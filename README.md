# Althea Colin Peranil — Personal Portfolio

🔗 **Live Site:** [https://altheaperanil.github.io/Peranil-Portfolio/](https://altheaperanil.github.io/Peranil-Portfolio/)

A single-page personal portfolio website built with HTML, CSS, and JavaScript for **CC107 – Activity 4: Application Development (Web Platforms)**.

---

## 📌 About

This portfolio introduces me, Althea Colin L. Peranil — a 3rd-year BS Information Technology student at Bulacan State University, College of Information and Communications Technology. It showcases my background, selected projects, and contact information.

---

## ✨ Features

- **Responsive Layout** — built with Flexbox and CSS Grid, fully mobile-friendly
- **Dark / Light Mode Toggle** — remembers the user's preference using `localStorage`
- **Mobile Hamburger Menu** — collapses navigation on smaller screens
- **Smooth Scrolling** — anchor links scroll smoothly between sections
- **Hover Effects** — interactive buttons, project cards, and social icons
- **YouTube Project Demos** — links to demo videos for each project

---

## 🛠️ Built With

- **HTML5** — semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- **CSS3** — Flexbox, Grid, CSS variables, media queries
- **JavaScript** — vanilla JS for theme toggle and navigation
- **Font Awesome** — icon library
- **Google Fonts** — Inter typeface
